# thefleece.github.io

The GitHub Pages site of this account. It holds one thing: a relay for
`thefleece.github.io/dota2-mod-manager/`, the address Dota 2 Mod Manager used before its repository
moved to [github.com/dota2modmanager](https://github.com/dota2modmanager). GitHub Pages does not
follow a repository that moves, and installed copies of the app and preset links already shared in
Discord still point here.

`dota2-mod-manager/` is a copy of the signpost pages that repository served from its `docs/` folder.
Each one sends the visitor to [dota2modmanager.com](https://dota2modmanager.com). `404.html` catches
any other path under `/dota2-mod-manager/` and sends it to the same path there.

While the project repository still serves its own Pages at that path, GitHub serves those
instead, so this copy only takes over once the repository has moved.
